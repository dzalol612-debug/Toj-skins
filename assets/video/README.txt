ВИДЕО-ИНСТРУКЦИЯ В ОКНЕ «УСТАНОВИТЬ»
====================================
1. Положи своё видео сюда, например: install.mp4  (формат mp4 или webm, лучше до 20 МБ — телефоны грузят быстрее).
2. В extras.js, в самом верху, найди INSTALL_VIDEO и впиши путь:
     const INSTALL_VIDEO = { src: 'assets/video/install.mp4', poster: '' };
3. Хочешь видео с YouTube — впиши ссылку «Встроить» (embed):
     const INSTALL_VIDEO = { src: 'https://www.youtube.com/embed/ТВОЙ_ID', poster: '' };
4. poster — картинка-обложка до запуска видео (файл из assets/images/, можно оставить пустым).

Пока src пустой, в окне показывается заглушка «Здесь будет видео-инструкция».
